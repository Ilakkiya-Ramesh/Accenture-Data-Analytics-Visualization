# 📊 Accenture – Data Analytics & Visualization

## 📌 Project Overview

This project is based on the Accenture North America Data Analytics and Visualization Job Simulation completed through Forage in June 2024.

The simulation focused on working as a Data Analyst for a hypothetical social media client and using data analysis and visualization to identify meaningful content trends.

---

## 🎯 Project Objective

The objective of the simulation was to analyze multiple datasets and uncover insights into content trends that could support strategic decision-making.

---

## 🔍 Project Work

During the simulation, I:

- Cleaned 7 datasets
- Modeled the available data
- Analyzed the datasets to identify content trends
- Extracted meaningful insights from the data
- Prepared a PowerPoint presentation
- Communicated key findings for the client and internal stakeholders
